# 课题研究思路概述与SVG绘制指南

本文档总结了“语义驱动的无人机集群具身任务与协同决策”课题的研究思路，并给出用于绘制对应概念关系图的 Python 示例代码。运行脚本可生成 `research_architecture.svg`，展示三大研究方向及关键要点。

## 研究思路

### 1. 语义驱动的无人机集群具身任务建模
- **目标**：搭建从自然语言指令到具身可执行动作的统一桥梁，避免语义鸿沟导致的执行偏差。
- **方法**：
  - 将任务语义解析为场景理解、行为原子与控制指令三层表示。
  - 构建语义到状态的双向对齐机制，结合情境知识库持续校验任务意图。
  - 设计可组合的行为原子库，支持多机动作的时序与空间协同。

### 2. 记忆增强的长时序分层决策
- **目标**：应对长时序任务中的策略遗忘与性能退化，实现稳健决策。
- **方法**：
  - 采用“阶段级—决策步级—控制周期级”多时间尺度分层策略。
  - 融合短期工作记忆与长期知识库，进行关键状态提炼与经验重用。
  - 借助策略自蒸馏与事件触发的记忆刷新，防止长序列干扰。

### 3. 异构集群的分布式协同决策
- **目标**：在通信受限和平台异构条件下，实现去中心化的高效协同。
- **方法**：
  - 建立面向任务分工的异构能力建模（平台性能、传感、负载）。
  - 采用分布式决策与局部通信协议，在邻域内完成协作与冲突消解。
  - 通过多任务约束下的自适应任务分配，兼顾公平性与效率。

## SVG绘制与运行方式
执行下方 Python 脚本可生成研究思路的分层关系图：

```bash
python scripts/generate_research_svg.py
```

生成的 `research_architecture.svg` 默认保存在项目根目录，可用浏览器直接查看。
